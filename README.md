# Shadermix

Animated shader backgrounds, visual effects, and text animations for **Astro**
and **Webflow** — framework-free at the core, zero runtime dependencies.

> Status: pre-v0.1, under active development. See `SHADERMIX_PLAN.md` for the
> full spec and `PROGRESS.md` for current progress.

## Packages

- `@shadermix/core` — vanilla TypeScript + WebGL runtime and all effects
- `@shadermix/astro` — `.astro` wrapper components
- `@shadermix/webflow` — CDN bundle for Webflow sites

## Development

```bash
pnpm install
pnpm build
pnpm test
```
